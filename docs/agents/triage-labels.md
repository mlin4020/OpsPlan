# Triage 标签

技能以五个标准 triage 角色来沟通。本文件把角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库 tracker 中的标签 | 含义                     |
| -------------------------- | ----------------------- | ------------------------ |
| `needs-triage`             | `needs-triage`          | 需要维护者评估该 issue   |
| `needs-info`               | `needs-info`            | 等待报告者补充信息       |
| `ready-for-agent`          | `ready-for-agent`       | 规格完整，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`       | 需由人工实现             |
| `wontfix`                  | `wontfix`               | 不予处理                 |

当某个技能提到某个角色（例如「打上 AFK-ready 的 triage 标签」）时，使用本表中对应的标签字符串。

本仓库的 tracker 是本地 Markdown，因此所谓「标签」就是每个 issue 文件顶部 `Status:` 行的取值。
